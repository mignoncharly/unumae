## Usage safeguards

- A visible localized label identifies each fallback as an editorial image and
  says the portrait is unavailable.
- A valid signed consented portrait always replaces the fallback.
- Removed Humans receive no image.
- Fallback images have empty alt text because the story, not the decorative
  still life, is the meaningful content.
